# Changelog

Each section is one firmware version. When the number in the `VERSION` file changes on `main`, GitHub publishes a release automatically. The section for that version becomes the release notes.

## 5.1.0

- The release now has a `.uf2` file for each firmware version (V4 and V5). GitHub builds the files automatically.
- The V5 firmware has many fixes and changes after release 5.0.0.
- Licences added: GPL-3.0 for the firmware and CERN-OHL-S-2.0 for the hardware.

## 5.0.0

- DRIFT: a second synth voice.
- Pattern chaining for the acid save slots.
- MIX EDIT: set the level of each engine.
- A custom drum pattern that you can edit.
- Sync in and sync out.
